## 🏁 Quick Start Guide

### Prerequisites

- Node.js & npm (for installing TypeScript compiler)
- PowerShell or Terminal access

### 1. Installation & Environment Setup

Clone or download the project files into a directory, then install TypeScript globally (if not already installed):

```bash
npm install -g typescript

```

### 2. Compile

Compile `app.ts` into JavaScript:

```bash
tsc app.ts
```
*Note :* User 'Live server' extension to run the frontend in the browser
